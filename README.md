# Daily Algorithm Training

我的每日算法训练仓库，用于持续提升算法能力，并服务于考研 / 软件工程算法准备。

## 训练目标

- 每天 2 道高质量算法题
- 难度以中等及以上为主
- 强化算法思维，而不是单纯刷题数量
- 使用 C++ 完成标准实现
- 总结算法模型、易错点和可迁移经验
